## 📌 Sobre o Projeto

Este é o meu portfólio pessoal, desenvolvido do zero para centralizar e apresentar minha trajetória profissional, formação acadêmica e os principais projetos que venho desenvolvendo.

A aplicação foi planejada focando em **experiência do usuário (UX)**, **design autoral**, **semântica HTML5** e **performance de carregamento**.

---

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias modernas de desenvolvimento web:

- **HTML5** (Estruturação semântica e acessível)
- **CSS3** (Layouts modernos com CSS Grid e Flexbox, variáveis nativas)
- **JavaScript (ES6+)** (Menu mobile e interatividades)
- **Figma** (Refatoração visual e prototipagem)
- **Minificação de CSS** (Otimização de performance para entrega rápida de recursos)

---

## 📱 Funcionalidades em Destaque

- **Design 100% Responsivo:** Interface milimetricamente ajustada para desktops, tablets e smartphones.
- **Menu Mobile:** Navegação fluida via menu hamburger interativo no mobile.
- **Seções Estruturadas:**
  - **Sobre:** Introdução profissional e objetivos.
  - **Experiência:** Linha do tempo de atuação profissional.
  - **Formação:** Cursos acadêmicos, stacks estudadas e credenciais de autenticidade linkadas diretamente à Origamid.
  - **Projetos:** Galeria de projetos desenvolvidos, com controle visual de status (_Concluído_ / _Em Andamento_) e links diretos para repositórios e deploys.
  - **Contato:** Cards simétricos de ação rápida para e-mail e redes sociais.
